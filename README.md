# python-mathematical-logic

Python implementations of the formal systems developed in
*Mathematical Logic through Python* (Gonczarowski & Nisan, 2022).

## Scope

- Propositional logic: syntax, semantics, satisfiability, normal forms
- Predicate logic: syntax, semantics, models
- Proof systems: deduction, soundness, completeness

## Structure

Each module corresponds to a chapter or section of the text and
implements its associated data structures and algorithms.

## Requirements

- Python 3.10+

In progress.
